# MVP Astra Taro

## Цель первой версии

Собрать рабочий Telegram-бот + Mini App, где пользователь может запустить бота, открыть Mini App, выбрать расклад, ввести вопрос и получить символический Таро-расклад через ИИ.

## Ограничения первой версии

- Реальная оплата не подключена.
- История пользователю пока не показывается.
- Используются только 22 старших аркана.
- Перевёрнутые карты пока отключены.
- Английской версии пока нет.

## Бесплатные механики

- Карта дня — 1 раз в сутки.
- Первый бесплатный расклад — любой на выбор.
